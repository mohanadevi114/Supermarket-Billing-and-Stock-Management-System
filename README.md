# Supermarket Billing and Stock Management System

## About the Project

The Supermarket Billing and Stock Management System is a Java-based desktop application developed using Java Swing and MySQL. This application helps manage supermarket products, generate customer bills, and maintain stock details efficiently.

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- VS Code

## Features

- Product management using barcode.
- Add and manage product details.
- Generate customer bills.
- Automatic bill total calculation.
- Store sales details in MySQL database.
- Automatically update product stock after billing.
- Generate and export reports.

## Project Structure

- `Main.java` – Main application.
- `DBConnection.java` – MySQL database connectivity.
- `Product.java` – Product details management.
- `ReportExporter.java` – Report generation.

## Database Details

- Database Name: `supermarket_db`
- Database: MySQL
- Connectivity: JDBC

## How to Run the Project

1. Install Java JDK.
2. Install MySQL Server.
3. Create the `supermarket_db` database.
4. Import the provided SQL file.
5. Configure database credentials in `DBConnection.java`.
6. Add the MySQL JDBC driver.
7. Open the project in VS Code.
8. Run `Main.java`.
